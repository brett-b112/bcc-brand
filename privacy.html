Privacy Policy — Brett Covers Capital

Effective date: October 26, 2026 · Contact: brett.balquist@gmail.com

1. About this application

Brett Covers Capital is a personal, single-user automation tool that helps its owner, Brett Balquist, produce short-form startup-news videos ("Shorts") and publish them to his own YouTube channel. This privacy policy explains how the application handles Google user data. It applies only to the owner's own use of the application; there are no other users.

2. Google user data we access

The application requests exactly one Google OAuth scope:

  • https://www.googleapis.com/auth/youtube.upload — permission to upload videos and manage those uploads on the owner's own YouTube channel.

No other Google data is requested, read, or accessed. The application does not access Gmail, Google Drive, Google Photos, Google Profile, contacts, calendar, analytics, or any other Google service. It does not read, modify, or delete any existing YouTube videos, comments, or channel settings belonging to the owner or anyone else.

3. How Google user data is used

  • Video uploads. The access token received from Google is used solely to upload video files created by the owner to the owner's own YouTube channel (@brett.covers.capital). Uploads are created as private or unlisted drafts; nothing is made public without the owner's explicit action.
  • Token storage. The OAuth refresh token is stored locally on the owner's own computer, in a file with restrictive permissions (.secrets/, owner-readable only). It is never transmitted anywhere except to Google's own OAuth and YouTube API endpoints.
  • No analytics. The application contains no analytics, tracking, logging to third parties, advertising, or data-sale mechanisms of any kind.

4. Sharing and disclosure

Google user data is never shared, sold, transferred, or disclosed to any third party, for any reason. There are no third-party integrations, servers, or subprocessors. All processing occurs on the owner's own machine and in direct communication with Google's APIs.

5. Compliance with the Google API Services User Data Policy

Use of Google user data is limited to the practices disclosed in this policy, in accordance with Google's API Services User Data Policy, including the Limited Use requirements.

6. Retention and deletion

OAuth tokens are retained locally only for as long as the owner uses the application. The owner may revoke the application's access at any time through Google Account → Security → Third-party apps with account access, after which all stored tokens stop working. The locally stored token file may also be deleted at any time without affecting the owner's Google account.

7. Data security

Tokens are stored with file-system permission restrictions on a private machine. No Google data is stored in any cloud service.

8. Changes to this policy

Changes will be posted to this page with an updated effective date.

9. Contact

For questions about this policy, contact Brett Balquist at brett.balquist@gmail.com.
